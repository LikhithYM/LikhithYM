### 1. [Yojak](https://github.com/LikhithYM/Yojak) — Decoupled Deterministic Governance for Autonomous Desktop Agents

> **Eliminating Tool Misuse and Unintended OS Mutations in Small Foundation Models**  
> *Autonomous AI Agents · Out-of-Band Security Kernel · Local SLMs*

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/LikhithYM/Yojak)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.111-009688?style=flat-square&logo=fastapi&logoColor=white)](https://github.com/LikhithYM/Yojak)
[![React](https://img.shields.io/badge/React-18-61DAFB?style=flat-square&logo=react&logoColor=black)](https://github.com/LikhithYM/Yojak)
[![Vite](https://img.shields.io/badge/Vite-Bundler-646CFF?style=flat-square&logo=vite&logoColor=white)](https://github.com/LikhithYM/Yojak)
[![Ollama](https://img.shields.io/badge/Ollama-Local_Models-white?style=flat-square&logo=ollama&logoColor=black)](https://github.com/LikhithYM/Yojak)
[![Playwright](https://img.shields.io/badge/Playwright-Automation-2EAD33?style=flat-square&logo=playwright&logoColor=white)](https://github.com/LikhithYM/Yojak)

* **The Problem**: Standard computer-use AI agents rely on system prompt instructions to remain safe. When facing indirect prompt injections or model hallucinations, software agents risk mutating system files, dropping unauthorized scripts, or executing unintended actions.
* **The Architecture**: Decouples **cognitive planning** from **execution authorization**. Before any tool action runs (PowerShell, browser clicks, or OS accessibility APIs), Yojak's deterministic security kernel intercepts the action out-of-band, evaluates risk, and validates boundary integrity.
* **Key Capabilities**:
  * **Four-Tier Risk Taxonomy**: Deterministically classifies operations into `LOW`, `MEDIUM`, `HIGH`, and `CRITICAL`.
  * **Human-in-the-Loop Interception**: High-risk operations (e.g. file deletions, terminal executions) automatically trigger a pause and display an interactive modal with live screenshots for explicit approval.
  * **Sub-2ms Policy Latency**: Pure deterministic rule matching executing with ~1.48 ms overhead per action.
  * **Local Small Foundation Model Optimization**: Runs completely on local consumer hardware (Qwen2.5-Coder-7B and Gemma-3-4B via Ollama).
* **Explore the Code**: [`LikhithYM/Yojak`](https://github.com/LikhithYM/Yojak)

### 2. [NeuroSent](https://github.com/LikhithYM/NeuroSent) — AI-Powered Cyber Threat Intelligence & Operational Dashboard

> **Real-Time Cyber Threat Detection Using Machine Learning Ensembles with Live Streaming Dashboard**  
> *Cybersecurity · Machine Learning · WebSockets · D3.js*

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white)](https://github.com/LikhithYM/NeuroSent)
[![FastAPI](https://img.shields.io/badge/FastAPI-Server-009688?style=flat-square&logo=fastapi&logoColor=white)](https://github.com/LikhithYM/NeuroSent)
[![scikit-learn](https://img.shields.io/badge/scikit--learn-1.5-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)](https://github.com/LikhithYM/NeuroSent)
[![D3.js](https://img.shields.io/badge/D3.js-Visualization-F9A03C?style=flat-square&logo=d3.js&logoColor=white)](https://github.com/LikhithYM/NeuroSent)
[![WebSockets](https://img.shields.io/badge/WebSockets-Live_Feed-010101?style=flat-square&logo=socketdotio&logoColor=white)](https://github.com/LikhithYM/NeuroSent)

* **The Problem**: High-velocity network environments produce overwhelming telemetry logs where zero-day anomalies and stealthy lateral movement get lost inside traditional signature-based firewalls.
* **The Architecture**: A multi-model machine learning pipeline that streams continuous predictions over high-speed WebSockets into a live security operations center (SOC) dashboard.
* **Key Capabilities**:
  * **Tri-Model Ensemble**:
    * **Isolation Forest**: Unsupervised anomaly detection for novel / zero-day vectors.
    * **Random Forest**: Supervised multi-class classification for known attack profiles (DDoS, brute-force, port scanning, SQL injection, malware C2).
    * **KMeans Clustering**: Unsupervised traffic behavior categorization.
  * **SHAP-Style Explainability**: Isolates top contributing network features for every threat alert to guide incident response.
  * **Interactive Operations Center**: D3.js world map with animated attack arcs, real-time alert feeds, and latency metrics.
* **Explore the Code**: [`LikhithYM/NeuroSent`](https://github.com/LikhithYM/NeuroSent)

### 3. [AuthentiCert](https://github.com/LikhithYM/AuthentiCert) — Intelligent Certificate Verification & Digital Forensics

> **Full-Stack Credential Authenticity Platform with OCR, Tampering Forensics & Database Cross-Referencing**  
> *Full-Stack · Computer Vision · Error Level Analysis · Tesseract OCR*

[![React](https://img.shields.io/badge/React-19-61DAFB?style=flat-square&logo=react&logoColor=black)](https://github.com/LikhithYM/AuthentiCert)
[![Vite](https://img.shields.io/badge/Vite-Fast_Build-646CFF?style=flat-square&logo=vite&logoColor=white)](https://github.com/LikhithYM/AuthentiCert)
[![Flask](https://img.shields.io/badge/Flask-Backend-000000?style=flat-square&logo=flask&logoColor=white)](https://github.com/LikhithYM/AuthentiCert)
[![OpenCV](https://img.shields.io/badge/OpenCV-Computer_Vision-5C3EE8?style=flat-square&logo=opencv&logoColor=white)](https://github.com/LikhithYM/AuthentiCert)
[![Tesseract OCR](https://img.shields.io/badge/Tesseract-OCR_Engine-4285F4?style=flat-square&logo=google&logoColor=white)](https://github.com/LikhithYM/AuthentiCert)

* **The Problem**: Manual verification of academic diplomas and certifications is labor-intensive and vulnerable to sophisticated digital forgery (edited text, mismatched typography, altered dates).
* **The Architecture**: End-to-end automated verification pipeline combining text extraction, automated web scraping against institutional records, and pixel-level forensic image comparison.
* **Key Capabilities**:
  * **High-Accuracy OCR Extraction**: PyTesseract and PyMuPDF pipeline extracting credential metadata, candidate details, and issue dates from PDFs and high-res images.
  * **Error Level Analysis (ELA) Forensics**: Inspects compression artifact discrepancies to expose digitally altered fields and spliced text.
  * **Structural Similarity (SSIM)**: Compares template layouts against official institutional baselines with similarity scoring.
  * **Forensic PDF Reports**: Automated ReportLab engine generating downloadable forensic verification audits for single submissions or bulk batches.
* **Explore the Code**: [`LikhithYM/AuthentiCert`](https://github.com/LikhithYM/AuthentiCert)
